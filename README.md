# 朵朵的 24 点

## 👉 在线地址：https://dew8788.github.io/duoduo-24/

在 iPad 的 Safari 里打开，点「分享 → 添加到主屏幕」，就是一个全屏 App。
电脑关机也能玩（页面会缓存到 iPad 本地）。

---

一个从零复刻的「算 24 点」游戏：**300 关闯关 + 儿童加减模式**，纯本地运行、不联网、无广告。
儿童模式算对之后，会有一个**小女孩举手欢呼的小动画**（纯 SVG + CSS，不依赖任何图片）。

> 参考原型：[4399《算24点》](https://www.4399.com/flash/193616.htm) —— 15 个难度 × 20 关 = 300 关，
> 用 4 张数字牌加减乘除凑 24。界面按原版逐像素复刻：白底、薄荷绿圆角横卡（2×2 宫格）、
> 橙色运算符、橙色爆炸贴「24」、绿色/橙色圆角按钮。
>
> 原版是 **Cocos Creator** 导出的项目（`Math24`），我们把它完整扒下来分析过：
> 它的 300 关答案是**硬编码字符串**，根本没有求解器，判等还靠浮点容差兜底。
> 本项目用的是**真正的精确分数求解器**，所以提示、答案、自由练习都不会出错。
> 详细分析见 [`docs/架构与AI原理.md`](docs/架构与AI原理.md)。

## 一、三种模式

| 模式 | 玩法 | 特点 |
|---|---|---|
| **闯关模式** | 300 关，15 个段位，由易到难 | 星级评价、进度自动保存 |
| **儿童模式** | **只用 ＋ 和 −**，目标同样是 **24** | 牌面 1~10、**不评分**、算对后有小女孩庆祝动画 |
| **自由练习** | 随机题目 | 四则全开，不计入进度 |

**15 个段位**（沿用原版的称号体系）：
幼儿园 → 小学生 → 初中生 → 高中生 → 大学生 → 研究生 → 博士生 →
副教授 → 教授 → 数学专家 → 阿基米德 → 祖冲之 → 高斯 → 图灵 → 数学之王

儿童模式的每一道题都由引擎验证过「只用加减必有一解」，不会出现无解的题目。
仅用加减凑 24 的可用牌面（1~10）共 56 道，全部收录、随机出题且不与最近 16 题重复。

## 二、怎么放到 iPad 上玩

### 方案 A：局域网（最简单，一次联网之后就不用再管电脑）

电脑和 iPad 连同一个 WiFi，在项目目录执行：

```bash
node tools/serve.mjs
```

（Windows 上也可以直接**双击 `启动服务器.cmd`**，它会打印出 iPad 要访问的网址。）

在 iPad 的 **Safari** 里打开它打印的地址，点「分享 → 添加到主屏幕」，桌面就会出现一个全屏图标。

**联网打开过这一次之后，电脑关机、断网都能照常玩。** 原理与实测：

| 场景 | 实测打开耗时 |
|---|---|
| 电脑关机后再打开 App | **44 ms** |
| 电脑卡住 / 网络超时 | **26 ms**（不会卡在等网络） |
| 电脑恢复联网 | 后台自动拉到新版，下次打开就是新的 |

这是靠 Service Worker 把整个应用外壳（约 90 KB）预先缓存到 iPad 本地实现的，
策略是「**先给缓存、后台更新**」——所以离线秒开，联网时又能收到后续改动。
可以自己跑 `python test/offline_test.py` 复验。

> ⚠️ 三个注意点：
> 1. **第一次必须联网打开一次**（电脑要开着），让它把缓存装好。
> 2. 别在 iPad 上「清除 Safari 网站数据」，也别在电脑关机时删掉主屏幕图标再加回来——
>    那样缓存就没了，需要重新联网装一次。
> 3. iPad 存储空间紧张时，iOS 理论上可能回收缓存；概率很低，但真有万一，重连一次即可。

### 方案 B：传到静态托管（一劳永逸，完全不依赖电脑）

`dist/` 里除了图标就只有一个 `index.html`，直接丢到 GitHub Pages / Vercel / Netlify /
对象存储（OSS、COS）即可，网址固定、永远在线，iPad 从新网址重新「添加到主屏幕」一次就行。
这是最省心的长期方案——毕竟方案 A 里"第一次要联网"这件事永远需要电脑在场。

### 方案 C：只要一个文件

`dist/index.html` 是**完全自包含的单文件**（CSS、JS、300 关数据、小女孩动画全部内联，约 90 KB）。
可以 AirDrop 到 iPad 用支持本地网页的 App 打开，适合临时给别的设备看，
但 iPadOS 不允许把本地文件「添加到主屏幕」，所以做不成桌面 App。

## 三、目录结构

```

├─ src/                     源码
│  ├─ engine.js             ★ 核心引擎：精确分数、求解器、提示、出题
│  ├─ levels.js             300 关数据（由脚本生成，勿手改）
│  ├─ app.js                界面与游戏逻辑
│  ├─ style.css             样式（iPad 触屏优先）
│  └─ index.template.html   页面骨架
├─ tools/
│  ├─ gen-levels.cjs        固化 300 关 → src/levels.js
│  ├─ make-icons.ps1        生成 PWA 图标（Windows）
│  ├─ serve.mjs             局域网测试服务器
│  └─ probe.cjs             难度分布统计（调关卡曲线用）
├─ build.mjs                内联打包 → dist/
├─ test/
│  ├─ engine.test.cjs       引擎测试（76 项断言，Node）
│  └─ ui_smoke.py           真实浏览器端到端测试（Playwright）
└─ dist/                    成品：index.html + PWA 资源
```

## 四、开发与测试

```bash
node tools/gen-levels.cjs     # 1. 固化关卡（改过 engine.js 之后要重跑）
node build.mjs                # 2. 打包到 dist/
node tools/serve.mjs          # 3. 本机起服务预览（或双击 启动服务器.cmd）

node test/engine.test.cjs     # 引擎测试：76 项断言，约 10 秒
python test/ui_smoke.py       # 浏览器测试：245 项断言，4 个场景，约 3 分钟
python test/offline_test.py   # 离线验证：9 项断言，约 20 秒
```

浏览器测试跑完会在 `test/screenshots/` 留下 29 张截图，可以直接看各个界面的实际样子。

引擎测试的核心是**交叉验证**：用另一套完全独立实现的求解器（5 种括号模板穷举）
把 1~13 全部 1820 个四数组合跑一遍，两边结论必须完全一致——而不是自己验自己。

浏览器测试覆盖的场景：

| 场景 | 内容 |
|---|---|
| iPad 竖屏 820×1180 | 全流程 + Service Worker 注册 + **断网后仍能打开** |
| iPad 横屏 1180×820 | 全流程 + 矮屏布局检查 |
| 手机竖屏 390×844 | 全流程（顺带验证更窄的屏幕也不溢出） |
| 单文件 file:// | 直接双击打开也能玩（无服务器、无 SW） |

每个场景都会真实点击走完：点选 → 合并 → 撤销 → 提示 → 答案 → **3 星结算** →
下一关用提示拿 **2 星** → 再看答案拿 **1 星** → 故意算错触发失败提示 → 逐级撤销 →
选关/章节页 → 儿童模式连做 4 题 → 切换目标值 → 自由练习 → 设置 →
**布局不溢出 / 触控目标 ≥40px / 全程无 JS 报错**。

## 五、调试接口

在网址后面加上 `?debug`（例如 `index.html?debug`），控制台会挂上 `__P24__`：

```js
__P24__.state()        // 当前牌面、目标、模式、是否通关
__P24__.solve()        // 当前盘面的下一步 + 完整解法
__P24__.startLevel(137)
__P24__.startKid()
```

这个接口只在带 `?debug` 时挂载，正常玩完全不受影响。

## 六、已实现的小细节

- **精确分数运算**：`8÷(3−8÷3)` 这类题不会因浮点误差判错
- **顺手的操作手感**：合并出来的牌**自动保持选中**，一关最少 7 次点击（和原版一致）
- **提示 / 答案**：提示点亮正确的两张牌；答案给出完整表达式
- **撤销 / 重来**：撤销支持最多 60 步回溯
- **星级**：闯关模式 3 星（全程没用提示答案）/ 2 星（用过提示）/ 1 星（看过答案）；
  **儿童模式不评分**
- **小女孩庆祝动画**：儿童模式答对后，小女孩举手欢呼 + 飘出爱心星星（纯 SVG + CSS）
- **进度存档**：localStorage 本地保存，不上传任何数据
- **触屏适配**：安全区适配、禁双击缩放、禁长按选择、横竖屏自适应、大触摸目标（≥44px）
- **音效**：WebAudio 实时合成，不依赖任何音频文件
- **无障碍**：尊重系统「减弱动态效果」设置
